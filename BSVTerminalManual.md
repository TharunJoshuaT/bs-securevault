# BS SecureVault — Native Terminal CLI Manual

> **Module:** `bsv` Native Binary  
> **Architecture:** Compiled Rust (x86_64 / ARM64)  
> **Security:** Argon2id Key Derivation + AES-256-GCM Authenticated Cipher  
> **Developer:** BS Operating Systems and Software Engines (BS OS SE)  

---

## Overview
The `bsv` CLI is a zero-dependency, hardware-accelerated terminal tool built for system administrators, engineers, and power users who require fast file encryption directly from their command shell.

---

## Installation & Build

### Building from Source
```bash
cargo build --release --bin bsv
The compiled binary will be located at ./target/release/bsv.

🚀 Usage Guide
1. Encrypting a File
To encrypt any file into a .bsv secure container:
Bash
./target/release/bsv encrypt -i <INPUT_FILE> -o <OUTPUT_CONTAINER.bsv>
-i, --input: Path to the raw source file.
-o, --output: Path to the destination .bsv file (optional, defaults to <input>.bsv).
Passphrase Prompt: The terminal will prompt you to enter and confirm your master passphrase with hidden terminal echo.

2. Decrypting a File
To restore a .bsv file back to its original state:
Bash
./target/release/bsv decrypt -i <CONTAINER.bsv> -o <RESTORED_FILE>
-i, --input: Path to the .bsv container file.
-o, --output: Path where the decrypted file will be saved.
Authentication Check: If the passphrase is incorrect or the file was modified, decryption aborts immediately with an authentication error.

🛡️ Binary Framing Format
Every .bsv file generated by bsv follows this strict layout:
Offset (Bytes)Header ComponentDescription
0..16Salt16-byte cryptographically secure random salt
16..28Nonce12-byte initialization vector
28..NPayload & TagAES-256-GCM ciphertext + 16-byte authentication tag
